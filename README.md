# StudentHub – Student Management System

## Project Description
StudentHub is a Student Management System developed for the CDIM262 Web Design & Development individual assignment. This project uses HTML, CSS, JavaScript, Bootstrap 5, and Chart.js.

## Features
- Login page
- Student dashboard
- Student information page
- Course information page
- Registration page
- Search functionality
- Charts and progress bars
- Responsive design for different screen sizes

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Chart.js 4.4.3

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser or use the Live Server extension.
